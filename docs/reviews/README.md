# Reviews

Every feel-critical feature is reviewed in a Lab and approved by the user before it enters the game (Plan Part 8.0). Each gets a file `<lab-name>.md` with:

- **Lab link:** the Artifact URL.
- **Rounds:** date, what changed, the user's feedback.
- **Approved values:** the final tuning copied into `src/data/tuning.ts`.
- **Status:** `in review`, `approved (date)`, or `integrated (commit)`.
