# Playtests

Every milestone ends with a user playtest of the build deployed to GitHub Pages. Record each one in `Mx.md` with this structure:

- **Build:** commit or tag, and the date.
- **Brief:** what the tester was asked to try, and what to listen for.
- **Benchmark:** the text block pasted from Settings → Benchmark.
- **Feedback:** raw notes, F8 captures and Sound Board notes.
- **Triage:**
  - Must-fix (blocks the next milestone)
  - Should-fix
  - Later
- **Resolutions:** a commit link for each item.
