# Decisions (ADRs)

This folder holds short records for decisions that future sessions might otherwise undo. Name each file `NNNN-short-title.md`.

Each record answers:
- **Context:** what forced a choice?
- **Decision:** what we chose.
- **Why:** the alternatives we rejected, and why.
- **Consequences:** what this commits us to.

The founding decisions are recorded in `docs/plan/00-assumptions-and-decisions.md` (Part 0.4).
